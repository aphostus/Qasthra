A new kind of internet.No IPs. No ports. No DNS.

Qast is a browser and network that reaches places by vector location instead of IP addresses and ports. There is no DNS to resolve names and no IP or port to guess. You do not look up a name. You travel to a point in space, and the machine computes the way there.

qast://X=1Y=2Z=3
  • Vector addressingEvery page, service and device sits at a coordinate. Closer points resolve faster.
  • Computed, not storedPowered by the Computational Database. Locations are computed and predicted, never kept in a lookup table.
  • Nothing to scanNo IP list or port range to sweep. A place is reached only by computing where it is.
  • No DNSNo domain names and no name servers. Nothing to register, poison or redirect, because places are found by position, not by name.
  • Direction and depthServices are reached by heading and distance, not by numbered ports.
  • Powered by the machineThe Computational Database predicts routes between vectors, so every path is computed on demand.

How a trip works

  1. 1Enter a vector such as X=1 Y=2 Z=3.
  2. 2The Computational Database computes the route to that point.
  3. 3The page or service is reached directly. No DNS lookup, no port.
